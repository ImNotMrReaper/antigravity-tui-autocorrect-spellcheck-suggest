# Antigravity TUI Autocomplete & Suggestive Text Assistance Rule

## 1. Intentional Typo & Command Normalization
- When the user types inputs in the interactive terminal with minor misspellings or phonetic slips (e.g. `antigravty`, `autocompleate`, `tehn`, `suod`, `reusme`), normalize intent automatically without asking redundant questions.
- Maintain high tolerance for fast stream-of-consciousness prompt sequences.

## 2. Technical Vocabulary Prioritization
- Prioritize project symbol nomenclature (`reaper_notes`, `EditorPage`, `AsciiArtEngine`, `Vulkan0`, `Goodix`, `Howdy`, `gy-link`, `Joy-Con`) during completion and interpretation.
